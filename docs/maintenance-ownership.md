# 宿主维护与运行资产

运行中的 DSH 将 runtime-host.mjs 作为 NODE_OPTIONS 预加载入口传给包管理与重启子进程。脚本必须比控制台安装目录和构建目录活得更久；BundledAssets 始终从内嵌资源生成按内容哈希区分的用户状态缓存，不返回发布目录里的同名文件，不自动回收旧缓存。升级只影响下一次由新控制台启动的宿主；无需重启当前会话来安装控制台。

依赖维护按实际修改目录决定运行端：DSH 安装目录和 web profile 对应 Web，desktop profile 对应官方桌面版，其他 profile 只检查静态组合。维护锁、目标核验和恢复点都完成后才停止受影响的宿主。成功按 RestartAfterUpdate 恢复原运行状态；失败回滚后尝试恢复原状态；依赖恢复失败则保留恢复点并报告。桌面依赖更新和备份恢复均使用同一流程，不能在加锁前停止桌面版，也不能在桌面回滚中停止 Web。

官方桌面 profile 不能使用 CLI dump-config 启动，使用官方桌面壳做 Host 验证，并在 finally 中结束验证进程。这个验证会短暂启动桌面版；维护确认窗口必须列出这一影响。任务看板的全局单写锁仍由插件拥有，不为验证删除锁文件或停止无关宿主。

健康检查只执行本地版本命令并读取清单、锁文件和客户端导出文件，既不安装依赖也不证明运行时 API 兼容性。npm / pnpm 受缺失预加载脚本影响时应报告实际 Node 错误。无保存状态时，端口检测优先 loopback 后端，防止把具体网卡上的转发进程误认成 DSH。

回归验证包括真实 npm / pnpm 的本地 registry 安装与冻结恢复、桌面验证失败后独立 Web 监听仍然响应、丢失客户端构建产物、同步未安装的精确声明、内容缓存预加载以及双主题最小窗口与筛选状态渲染。

会话记录的读取对象是现存会话目录和官方标题投影缓存，不取得日志写锁、不解压历史日志、不迁移格式、不挂载 Agent。分片优先于旧版整表缓存，无法读取的缓存保留目录行并计数提示；只有缓存而实际目录已删除的会话不出现。标题与轮数是缓存中的历史值，不用于判断实时 Agent 状态。公开渲染使用演示会话，避免发布真实标题。

液体玻璃使用 Windows 11 桌面亚克力，材质层提供透明填充与反光边缘；系统不支持、关闭透明度或开启高对比度时回退。官方标志沿用 FishLogo 原始几何，仅改变填充色。关闭窗口时终止动画，最小化时暂停；系统关闭客户端动画时显示静态彩虹填充。渲染验证对比两帧像素，另检查搜索、工作目录筛选与材质开关。
