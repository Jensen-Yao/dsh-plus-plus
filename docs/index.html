它帮你做什么

DSH 本体是一套命令行工具；dsh++ 把日常操作收进桌面窗口，并替你盯住容易出错的环节。

🚀

启动与远程

一键启动、停止、重启 DSH Web；手机经同一 Wi-Fi、Tailscale 或自定义域名访问，地址一键复制。

🧩

插件更新，看得懂

为什么装不上、声明是什么、怎么解除，提示都说清楚；「升级到最新」可选固定版本或浮动声明。

🛡️

防不兼容

更新前核对插件的内核要求，版本不够先拦截并给指引——不再装完才发现打不开。

🖥️

官方桌面版

启停官方桌面壳、同步 Web 配置、走官方通道更新；两端插件版本一页对照。

⬆️

内核升级

正式 / RC / 预览三通道，升级前自动备份，失败一键回滚，官方伴随包自动同步。

🩺

健康诊断

配置损坏、来源异常、中断任务提前发现；overlay 配置坏了，一键修复。

三步开始

需要 Windows 10/11、.NET 8 Desktop Runtime、Node.js 与已安装的 DSH

解压发布包完整解压 win-x64.zip，保留 EXE、compat-polyfill.js 与 scripts 目录，放入固定位置。
确认路径并启动在「数据与路径」确认 DSH 安装目录，从「服务总览」启动，等待"运行中"。
打开 DSH点「打开 DSH」进入 localhost；手机访问在「远程连接」选择局域网、Tailscale 或域名。

常见问题

更新与兼容的大多数疑问，答案都在界面提示里

提示「有新版（声明 范围外）」或「固定 版本」，怎么升级？

这是依赖声明把新版挡住了。选中插件点「升级到最新」，可选固定到新版或改为 ^ 浮动声明（之后普通更新即可继续升级）。0.x 包的 ^ 只跟随同一小版本。

提示「需内核 ≥x.y.z」？

插件要求更高的 DSH 内核。先在「版本与备份」升级内核（正式 / RC / 预览），再回来更新插件。

官方桌面版打不开？

多数是 cordis.patch.yml 被官方插件安装器写坏。到「诊断与日志」重新检查，按提示点「修复 overlay patch」即可（自动备份原文件）。

Web 和桌面版能同时开吗？

可以。任务看板有单写锁，同时运行时后启动一端的看板会降级；聊天、会话与插件界面不受影响。

会话数据会被修改吗？

不会。「会话记录」页只读列出标题与活动时间，不解压、不迁移、不改写任何官方数据。
