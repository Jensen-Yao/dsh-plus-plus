让手机打开和电脑一样的界面

把 dsh web 从命令行搬进一个漂亮的桌面应用——一键启停、手机地址、Tailscale、防火墙、存储位置，全部集中管理；手机随时连上同一个会话，思考过程完全同步。

Windows 10/11.NET 8 · WPF深浅双主题 Tailscale手机远程免扫码MIT
下载最新版 查看 README

功能

一个窗口，管好 dsh 的全部日常操作

一键启停

启动 / 停止 dsh web，实时显示运行状态与对外绑定（0.0.0.0 全网卡 或 127.0.0.1 仅本机）。

手机入口

同一 Wi-Fi / 自定义域名 / Tailscale 三种方式，大字地址一键复制，附「缺什么点什么」检查清单。

Tailscale 集成

登录 / 连接 / 断开 / 安装一体化，跨网络也完全实时，状态与 ts.net 域名实时显示。

存储位置管理

settings / sessions / storages / profiles / skills / agent-presets 一页看清；技能与 MCP 位置一键直达，主目录可直接修改。

免扫码直连

一键关闭手机远程插件的配对门禁，手机打开地址即可使用。

兼容补丁自愈

自动为网页入口注入 polyfill，旧手机浏览器也能用；npm 更新覆盖后自动重新注入。

三步上手

从下载到手机打开，不超过两分钟

启动服务下载发布版双击运行，在「① 服务开关」点「▶ 启动服务」，几秒后状态点变绿。
复制手机地址切到「② 手机入口」，选好连接方式（推荐 Tailscale），点「复制手机地址」发到手机。
手机打开手机浏览器打开地址，和电脑看到的是同一个会话，思考过程逐字同步。

从源码构建

Windows 10/11 + .NET 8 SDK，已安装 DeepSeek Harness（≥ 0.1.0-rc.6）

git clone https://github.com/Jensen-Yao/dsh-plus-plus.git
cd dsh-plus-plus
dotnet publish dsh-plus-plus.csproj -c Release -r win-x64 -o publish
# 产物：publish/dsh-plus-plus.exe + compat-polyfill.js

无窗口自检：dsh-plus-plus.exe --smoke（诊断写到 %TEMP%\dsh-control-smoke.txt）
