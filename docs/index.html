功能

一个窗口，管好 dsh 的全部日常操作

一键启停

启动、停止与重启 dsh web，验证网页就绪。本机入口保持 localhost，远程入口绑定所选网卡的具体 IP。

手机入口

同一 Wi-Fi / 自定义域名 / Tailscale 三种方式，大字地址一键复制，附「缺什么点什么」检查清单。

Tailscale 集成

登录 / 连接 / 断开 / 安装一体化，跨网络也完全实时，状态与 ts.net 域名实时显示。

存储位置管理

settings / sessions / storages / profiles / skills / agent-presets 一页看清；技能与 MCP 位置一键直达，主目录可直接修改。

插件维护与恢复

按来源、状态和 profile 筛选插件；精确版本与本地链接保留。维护前确认范围，记录阶段与结果，中断后可明确恢复。

兼容补丁自愈

自动为网页入口注入 polyfill，旧手机浏览器也能用；npm 更新覆盖后自动重新注入。

Freebuff 独立组件

不随 dsh++ 自动启动；在「Freebuff」页单独启停。连接信息默认隐藏，可显示或复制。

快速上手

需要已安装 DSH、Node.js 和 .NET 8 Desktop Runtime

确认安装完整解压发布包，在「数据与路径」确认 DSH 安装目录和数据目录。
启动服务在「服务总览」启动，等待网页就绪后打开 DSH。
远程连接（可选）在「远程连接」选择连接方式，在「启动设置」关闭仅本机访问并重启。新配置默认要求远程配对。
维护插件在「插件管理」检查版本并勾选更新；维护记录与恢复点位于「版本与备份」。

Freebuff 本地服务

可选组件，不随 dsh++ 启动，需要时在「Freebuff」页单独启动 / 停止

Base URL: http://127.0.0.1:18080/v1
API Key:  使用本机配置的值

项目目录：F:\freebuffapi
配置文件：F:\freebuffapi\.env

客户端 Provider 由你自行配置；修改端口或本地 Key 后，重启 Freebuff 服务即可。

从源码构建

Windows 10/11 + .NET 8 SDK，当前启动流程已在 DSH 0.2.1-rc.2 验证

git clone https://github.com/Jensen-Yao/dsh-plus-plus.git
cd dsh-plus-plus
dotnet publish dsh-plus-plus.csproj -c Release -r win-x64 -o publish
# 产物：完整 publish 目录，保留 EXE、compat-polyfill.js 与 scripts

无窗口自检：dsh-plus-plus.exe --smoke（诊断写到 %TEMP%\dsh-control-smoke.txt）
